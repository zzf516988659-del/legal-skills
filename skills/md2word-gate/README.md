## 二、交付物

### 2.1 新增 skill：`md2word-gate`

**路径**：`~/.openclaw/workspace/skills/legal-skills-github/skills/md2word-gate/`

**结构**：
```
md2word-gate/
├── SKILL.md                          # skill 说明
├── README.md                         # 本落地报告
└── scripts/
    └── md2word_gate.py               # 门禁核心脚本（11.8 KB）
```

**功能**：
1. OpenXML 结构完整性检查
2. 页眉页脚存在性检查
3. 页码字段检查（PAGE 字段 vs 硬编码）
4. 标题样式引用检查
5. 表格边框检查
6. 字体合规检查（仿宋_GB2312 + Times New Roman）
7. 中文标点全角检查（**关键**）
8. 空段检测
9. 字符数与段落数统计
10. 渲染页门禁（**可选**，需 LibreOffice + Poppler，v0.2.0 实现）

**依赖**：
- **必装**：`python-docx`（已具备）
- **可选**：`LibreOffice` + `poppler-utils`（渲染页门禁，WSL2 暂未安装）

## 四、整合到现有工作流

### 4.1 MEMORY.md 更新

应在 MEMORY.md"文书输出"流程的"第二步：转 Word"中追加：

```markdown
# 旧
python3 .../md2word/scripts/md2word.py <输入.md> --preset=legal -o <输出.docx>

# 新（追加门禁）
python3 .../md2word/scripts/md2word.py <输入.md> --preset=legal -o <输出.docx>
python3 .../md2word-gate/scripts/md2word_gate.py <输出.docx>
# 退出码 ≠ 0 则打回修正
```

### 4.2 退出码语义

| 退出码 | 含义 | 处理 |
|---|---|---|
| 0 | 全部通过 | 可对外发送 |
| 1 | 有警告（非严格模式） | 人工复核后发送 |
| 2 | 有失败 | **必须修正后重新生成** |
| 3 | 文件错误 | 检查文件路径/格式 |

## 五、设计原则

完全继承文格的三不原则：

> **"能执行的执行。能检查的检查。能证明的证明。证明不了的地方，直接报告给人。"**

- **能检查的**（OpenXML 结构、字体、标点、页码字段）→ 程序检查
- **不能检查的**（页面是否好看、内容是否准确）→ 报告给人
- **不擅自修改原 DOCX**，只输出门禁报告
