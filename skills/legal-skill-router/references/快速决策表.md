# 法律任务路由快速决策表

> 致用法务：收到用户请求时，先查本表 → 1 秒判定任务类型 → 调对应 skill。

## 一、单任务（30 秒判定）

| 用户说 | 任务 | 调谁 |
|---|---|---|
| "清理标点" / "去 AI" / "改格式" | 清理格式化 | `de-ai-polish` |
| "转 Word" / "出 DOCX" / "出文件" | 转 Word | `md2word`（+ `md2word-gate` 如正式/对外） |
| "出 X 份律师函" / "出催告函" / "按模板" | 模板生成 | `contract-templates` |
| "审查合同" / "审核" / "评审" | 合同审查 | `contract-copilot` |
| "起草合同" / "拟合同" / "写合同" | 合同起草 | `contract-copilot` |
| "分析案件" / "应诉" / "答辩" | 案件分析 | `litigation-analysis` |
| "出方案" / "出建议书" / "出报告" | 法律服务方案 | `legal-proposal-generator` |
| "法院短信" / "传票" / "开庭" | 法院短信 | `court-sms` |
| "查法条" / "查判例" / "类案" | 法条检索 | `yuandian-law-search` |
| "建档" / "新案" | 案件建档 | `new-case` |
| "抓微信文章" / "公众号" | 微信文章 | `wechat-article-fetch` |
| "OCR" / "识别扫描件" | OCR | `paddle-ocr` / `funasr-transcribe` |

## 二、混合任务（拆分为子任务）

| 用户说 | 拆分 | 调用顺序 |
|---|---|---|
| "审查合同 + 出修订版 + 转 Word" | 审查 → 转 Word | contract-copilot → md2word → md2word-gate |
| "起草律师函" | 模板 | contract-templates |
| "法院短信 + 怎么应诉" | 短信 → 应诉 | court-sms → litigation-analysis |
| "微信文章 + 入库" | 抓取 → 格式化 | wechat-article-fetch → legal-text-format |
| "查类案 + 出咨询报告" | 类案 → 报告 | yuandian-law-search → legal-proposal-generator |

## 三、必须先问用户

| 用户说 | 歧义点 | 问什么 |
|---|---|---|
| "整理一下" | 任务类型完全不确定 | "整理标点？转 Word？出报告？" |
| "出文件" | Word/PDF/邮件 | "出什么格式？给谁看？" |
| "看看这个" | 审查/分析/OCR/分类 | "您想看什么？审查风险？分析案情？" |
| "改一下" | 内容/格式/标点 | "改内容？改格式？改标点？" |

**绝对禁止**：在歧义时自动猜测——这是文格要避免的"任务入口混掉"。

## 四、特殊判断

| 场景 | 判断 |
|---|---|
| 用户说"方案" | → `legal-proposal-generator` 走"诉讼服务方案"或"非诉服务方案" |
| 用户说"建议书" | → `legal-proposal-generator` 走"法律服务建议书"（**不**降级为方案） |
| 用户说"按模板" | → 优先 `contract-templates` |
| 用户提到"对外发送" | → 必须走 `md2word-gate` 门禁 |
| 用户提到"批量" | → 优先 `contract-templates`（多份同模板） |
| 用户提到"紧急" | → 跳过去 AI 化（耗时步骤） |
