# evidence-cross-examination · 5 段式质证意见模板

**版本**: 1.0.0  
**最后更新**: 2026-06-03  
**来源**: 沈美娟案复盘 + 永天涂料案实战 + 周春明案复盘

## 5 段式结构

```
1. 证据真实性（原件/复印件/来源）
2. 证据合法性（形式合法性）
3. 证据关联性（与争点的关联度）
4. 证明力评估（强/中/弱）
5. 反驳话术 + 程序应对
```

## 证据分类标准

| 类别 | 典型证据 | 质证重点 |
|---|---|---|
| **书证** | 合同、协议、收据 | 真实性+合法性 |
| **物证** | 现场照片、物品 | 关联性+证明力 |
| **证人证言** | 证人书面/当庭陈述 | 可信度+关联性 |
| **鉴定意见** | 鉴定报告 | 合法性+证明力 |
| **视听资料** | 录音、录像 | 合法性+完整性 |
| **电子数据** | 微信记录、邮件 | 完整性+真实性 |
| **当事人陈述** | 当事人书面陈述 | 真实性+程序性 |

## 质证意见标准（每条证据）

```
【证据 X】：《XXX》（原告证据 X）

1. 真实性：原告提交的是原件/复印件/扫描件。
   - 若是复印件/扫描件：未与原件核对，不符合证据形式要求，对其真实性**不予认可**。
   - 若是原件：形式真实性无异议，但**内容真实性**由法庭审查。

2. 合法性：该证据**形式**合法（取得方式不违反法律规定），但**内容合法性**需结合其他证据综合判断。

3. 关联性：该证据与本案的争点 X 关联，但**证明力有限**——
   - 与争点 Y 关联度较弱
   - 与争点 Z 无关联

4. 证明力评估：**中**（结合其他证据综合判断）
   - 单独不能证明 X
   - 需结合证据 Y/Z 才能形成完整证明链

5. 反驳话术：
   - "该证据系原告单方制作，未经被告核实，对其**真实性不予认可**"
   - "该证据与本案争点**无直接关联**，不能证明原告主张"
   - "该证据**形式有瑕疵**（如无签字、无盖章），不符合证据法定形式"

6. 程序应对：
   - 若对方当庭提交新证据：申请**庭后核实**+ **举证期限延长**
   - 若对方申请鉴定：申请**鉴定人出庭**+ **质询权**
   - 若对方申请证人出庭：申请**对质权**
```

## 常见反驳话术库

| 情形 | 话术 |
|---|---|
| 复印件/扫描件 | "未与原件核对，对其**真实性不予认可**" |
| 无签字/盖章 | "形式不完整，不符合**证据法定形式**" |
| 证人未出庭 | "依据民诉法第七十二条，**证人应当出庭作证**，未出庭的证人证言**不能作为定案依据**" |
| 鉴定机构无资质 | "鉴定机构**超越资质范围**，鉴定意见**不应采信**" |
| 录音录像 | "取得方式**侵犯第三人合法权益**（如偷录），**合法性存疑**" |
| 微信记录 | "电子数据**完整性存疑**——是否经过**删改**需第三方鉴定" |
| 当事人单方陈述 | "系**原告单方陈述**，未经被告核实，**真实性不予认可**" |
